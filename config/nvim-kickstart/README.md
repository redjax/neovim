# Kickstart

My Neovim configuration, based on/seeded from [`kickstart.nvim`](https://github.com/nvim-lua/kickstart.nvim).

## Requirements

- `git`
- `make`
- `unzip`
- `gcc`
- Clipboard tool (`xclip`, `xsel`, `win32yank`, etc)
- `ripgrep`
- `fd-find`
- `tree-sitter-cli`
- (Optional) [Nerd Font](https://www.nerdfonts.com/)
- (Optional) NodeJS/`npm`
- (Optional) Go
